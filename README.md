### About

I build end-to-end machine learning systems: data pipeline, model, evaluation, and a usable interface on top. My focus is models that people can check and trust, with explanations, honest validation, and a human making the final call.

- Research contributor on a **temporal ultrasound needle-segmentation** project at York University (PyTorch, MONAI, Swin Transformer + ConvLSTM)
- Interested in ML for **healthcare**, **finance**, and **enterprise data**

| [**Credit Risk Decision Support**](https://github.com/Justin-Fekri/ai-credit-risk-loan-decision-support) | Scores 12-month default risk, explains each score with TreeSHAP, and routes files to an underwriter workbench. 0.799 ROC-AUC on a 2,400-record holdout. | Python, XGBoost, SHAP, FastAPI, Next.js |
